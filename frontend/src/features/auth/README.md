# features/auth

Pantalla de login (y, si el tiempo lo permite, registro) con correo institucional `@uvg.edu.gt`. Validación de formulario con React Hook Form + Zod, consistente con la restricción de dominio aplicada también en el backend (ver [ADR-0004](../../../../docs/adr/0004-institutional-authentication.md)).

Alcance mínimo aceptado por restricción de tiempo: ver `docs/08-roadmap.md`, sección 2 (posible simplificación a login sin registro público).
