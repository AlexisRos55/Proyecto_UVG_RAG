# features/chat

Interfaz conversacional del estudiante: envío de preguntas, indicador de "escribiendo" (FR-12), visualización de respuestas y del caso explícito "no tengo información" (FR-08), historial de conversación (FR-14).

Consume el endpoint `POST /chat` del backend a través de TanStack Query. Es la feature de mayor prioridad del frontend (ver `docs/07-backlog.md`, EPIC-4).
